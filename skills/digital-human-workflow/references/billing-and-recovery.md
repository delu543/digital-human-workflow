# 计费、恢复与版本

`job.json` 是任务阶段、供应商 ID、预算预留的真源；`receipts/` 保存原始回执，`profile.json` 与原稿是该任务固定输入。长期配置可调，恢复时仍核对当前授权和账户路径。不要只凭聊天“已经生成”跳过素材校验。

| 情况 | 正确动作 |
|---|---|
| 已有远端 ID，生成未完成 | 查同一 ID；仅在当前工具允许时等待/查询 |
| 收费请求超时且无 ID/回执 | 结果不确定；核对供应商历史后恢复 ID，禁止盲目再次 POST |
| 已有 MiniMax 回执、音频尚未写完 | `speech` 复用回执，不再次合成 |
| 下载 URL 过期 | 在允许的工具内刷新同一视频回执，然后 `receive` |
| 云端失败/余额不足/无权限 | 保留已成功配音与状态；不换账单，不自动新收费任务 |
| 音视频已完成，字幕或渲染失败 | 只修复本地阶段；同一媒体导入新包装版本即可 |
| 已有成片，需要改字幕/配图 | 新建本地版本，导入原声像，不覆盖已交付内容 |
| 渲染中断留下不完整文件 | 保留供核对；新本地版本导入原素材后重渲染，不重做云端声像 |
| 原素材/配置哈希变化 | 找回原文件或建立新任务；不能假装旧结果仍对应新输入 |

费用根据用户实际账户填写，不在产品内写死价格/套餐。预算单位分开保存 USD 与 HeyGen credits，保守估计加入 `price_buffer`。MiniMax 使用 UTF-8 字节数作为字符费用的保守上界，HeyGen 使用实际音频分钟；最终按供应商账单核对。克隆、预览和激活短配音均计算，未知报价停止该收费步骤。单条上限是本工具的估算提交限制，无法强制控制供应商发票、其他客户端消费或账户全月总额。价格超过31天需重新核对。

会员 MCP OAuth 使用会员相关额度；API 用独立 API 权限与计费。应向用户说明实际可用性和自动化限制，用户自主选择。已有授权覆盖的相同预算/模板任务直接执行；增加上限、换数据地区、换身份/音色、切换计费路径须新的具体决定。


## 质量、长度与订阅如何关联

不在仓库固定套餐价格或把某个模型称为永久最好。每条制作前记录当前账户的模型支持、原生输出分辨率、单次片长、剩余额度、素材训练权限、水印条件、单位费率与计费取整。官方起点：[HeyGen 订阅](https://www.heygen.com/pricing)、[HeyGen 开发者文档](https://developers.heygen.com/)、[MiniMax 模型与计费](https://platform.minimax.io/docs/api-reference/speech-t2a-http)。核对日期随任务保存。

| 条件 | 对交付的影响 |
|---|---|
| 目标引擎可用且有足够额度 | 才能按该模型执行；套餐名称不能替代具体 look/engine 权限 |
| 原生分辨率/水印受限 | 如实使用支持规格；上采样不冒充更多细节，不去除平台要求水印 |
| 单次时长受限 | 在自然语句边界分 reel，保存同一声学时间映射；不绕过总额度或条款 |
| 只在部分镜头出现人物 | 可只生成实际出镜语音与少量缓冲，其他时段用内容相关插片 |
| 全程圆形人物 | 必须覆盖所有主讲台词；通常比 selective 消耗更多人物秒数 |
| 模板/参考本身不足 | 高价订阅和高分辨率不能自动修复眼神、表情、场景或停顿 |
| 本地资源不足 | 降低并发、准备磁盘、增加合理导出时间；不自动降级人物模型 |

人物费用 = 各实际生成 reel 按供应商取整计费之和 + 明确需要的 look/训练/短校准。声音费用包括完整主讲、其他角色、克隆/激活和授权试听；素材生成与采购单列。重用已认可音轨和人物、实拍插片与本地后期不新增云端生成费，但本地仍有执行时间与磁盘成本。

用“主片时长 × 单价”估算可能错：continuous_pip 与 selective 的覆盖不同，短样片、重复候选、段落缓冲和取整均计费。先用 coverage 规划器得到 generation_seconds/reels，再按当前价格计算保守上界。用户决定预算，Codex 负责少量候选与停止条件，不让“质量优先”变成无限消费。
