# 计费、恢复与版本

`job.json` 是任务阶段、供应商 ID、预算预留的真源；`receipts/` 保存原始回执，`profile.json` 与原稿是该任务固定输入。长期配置可调，恢复时仍核对当前授权和账户路径。不要只凭聊天“已经生成”跳过素材校验。

| 情况 | 正确动作 |
|---|---|
| 已有远端 ID，生成未完成 | 查同一 ID；仅在当前工具允许时等待/查询 |
| 收费请求超时且无 ID/回执 | 结果不确定；核对供应商历史后恢复 ID，禁止盲目再次 POST |
| 已有 MiniMax 回执、音频尚未写完 | `speech` 复用回执，不再次合成 |
| 下载 URL 过期 | 在允许的工具内刷新同一视频回执，然后 `receive` |
| 云端失败/余额不足/无权限 | 保留已成功配音与状态；不换账单，不自动新收费任务 |
| 音视频已完成，字幕或渲染失败 | 只修复本地阶段；同一媒体导入新包装版本即可 |
| 已有成片，需要改字幕/配图 | 新建本地版本，导入原声像，不覆盖已交付内容 |
| 渲染中断留下不完整文件 | 保留供核对；新本地版本导入原素材后重渲染，不重做云端声像 |
| 原素材/配置哈希变化 | 找回原文件或建立新任务；不能假装旧结果仍对应新输入 |

费用根据用户实际账户填写，不在产品内写死价格/套餐。预算单位分开保存 USD 与 HeyGen credits，保守估计加入 `price_buffer`。MiniMax 使用 UTF-8 字节数作为字符费用的保守上界，HeyGen 使用实际音频分钟；最终按供应商账单核对。克隆、预览和激活短配音均计算，未知报价停止该收费步骤。单条上限是本工具的估算提交限制，无法强制控制供应商发票、其他客户端消费或账户全月总额。价格超过31天需重新核对。

会员 MCP OAuth 使用会员相关额度；API 用独立 API 权限与计费。应向用户说明实际可用性和自动化限制，用户自主选择。已有授权覆盖的相同预算/模板任务直接执行；增加上限、换数据地区、换身份/音色、切换计费路径须新的具体决定。
