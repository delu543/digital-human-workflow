# 出镜覆盖、分段生成与圆形画中画

用于用户要求只生成露脸段、全片持续看到本人、或在已交付片上补圆框。先定覆盖策略再付费，避免做完整片后发现插片期间缺口型。

## 按头部取景，避免“画布居中但人偏了”

采样开头/中段/结尾及转头、手势、身体移动，记录原像素中的完整头部范围（包含头发，不能只用眼鼻检测框）。以头部中心的稳健统计和活动包络设计方形裁切，再在后期用圆形蒙版显示。不要依赖视频中心点或一帧脸的位置。

`scripts/production_tools.py crop --plan <私人取景.json> --out <新裁切计划.json>` 根据 `examples/presenter-framing.json` 返回方形crop、FFmpeg过滤器、中心位置和过大运动提示；不自动检测人脸、不改五官、不运行视频模型。Codex可用本机视觉检测或检查帧提供头部框，复核后再执行裁切。

方形代理的帧数、帧率、时长与源片一致，不加fps滤镜、补帧、变速或循环。蒙版容器保持等宽高，内部方形视频填满，不同时在多层应用不一致的缩放/位移。圆框直径按画幅与版面决定，例如约短边的18%–25%可作为试排起点；实际检查字幕、画面主体和人脸清晰度，不能写死像素。

头部活动太大无法稳定保全时，改变构图/圆框大小或采用经过检查的平滑跟踪；不要每帧跳动追脸。确认最终渲染使用了裁切代理：个别渲染路径可能忽略CSS取景参数。完整成片还需核对 [声画时钟](captions-sync.md)，裁切正确不代表台词正确。

## 两种合法策略

- `selective`：只生成全屏或明确出镜窗口与主讲语音的交集。节省人物时长，插片期间可以没有人物。
- `continuous_pip`：所有主讲语音区间都必须有同台词的生成数字人；图解/插片上显示圆框。主讲静默、倒计时、其他角色说话不需要伪造主讲口型，可用闭嘴静态头像、已有合格听者动作或按要求隐藏。

默认沿用用户选择；未选择时按简报与预算提出方案。continuous_pip 不是“免费把头像贴上去”，也不是把一段无关说话素材循环。先算实际缺口，再报价。不为缩小头像而降低已约定的声音/人物模型。

## 可执行的覆盖规划

Codex 根据实际音轨写 `examples/presenter-coverage.json` 同格式的私人计划，再执行：

```sh
.venv/bin/python scripts/plan_presenter.py --plan /path/to/coverage-input.json --out /path/to/coverage.json
```

`main_speech` 排除其他角色与静默；`full_screen` 是大画面出镜区间；`available` 只填实际已有、声像验收且音轨对应的覆盖。`generation_units` 是完整语句/气口边界，包含实际需要的缓冲；不能从字数猜时间。工具会先求并集、扣除已有覆盖，再把缺口扩大到安全语句，按单次时长限制装入 reels，使用整数音频 sample 保存原音轨与拼接源的映射。相邻语句边界保留，超长语句明确报错，不静默断词。

该命令只规划，不生成、不自动计费。`generation_seconds` 包含语句扩展，是后续报价基础；每个 reel 的计费取整按当前供应商计算，不能用缺口裸秒数冒充费用。已有素材窗口只覆盖一半语句时，可能需要补整句；原片仍保留。

Codex 用映射从已认可完整配音裁出 reel 音频，禁止重新 TTS；每个 reel 建立正常 DH 生成任务，继承已认可声像组合并关联父片。使用既有 quality-plan/voice-review/submit 或官方 MCP 路径，不能绕过预算与请求状态。保存每条视频 ID、音频样本数、实际请求/回执和费用。先准备少量并按供应商限制调度，不重复已提交任务。

映射关系：`源片时间 = reel_start_sample / sample_rate + (成片时间 - timeline_start_sample / sample_rate)`。对任何拼接、变速、插入静默统一驱动画面、音频和字幕；不只移动其中一轨。provider 回片帧取整可产生一帧量级差异，应比较实际音轨与源窗口，不能仅靠时长相等判断同步。

通用 `DH run` 的默认输入仍是一条完整人物素材；分段 reel 方案是 Codex 用本工具规划、现有生成接口与自定义 Hyperframes 组装的高级分支，**没有**伪称自动 `run` 已内置整部片的多 reel 编排。用 `edit-seal`/`seal-project` 冻结实际工程；后续按 render-recovery.md 导出、登记和检查。

## 圆框布局与裁切

初始参考值：直径约画宽的 22–28%，距右边约 5–7%，底部留平台控件安全区。全部是起点，不是固定客户模板；按实际头部大小、平台遮挡和画幅调整。裁切包括完整头部、两侧余量与少量上肩，检查全程头部运动范围，不靠把整个人压扁塞进框。

先在源尺寸确定正方形 face crop，再缩放到圆框。若滤镜/渲染管线忽略 object-position，先本地裁出同时间、同帧率的画中画代理片，并保存裁切与时间映射。不要重新云端生成；勿改变说话节奏或音调。旧通用 `mask:circle` 已修正为等轴圆形，具体头部取景仍由该用户的素材决定。

自定义 Hyperframes 片段中：

```html
<!-- 使用已裁成正方形的本地视频；占位秒数由真实时间映射替换。 -->
<div class="pip-window" style="position:absolute;right:6%;bottom:8%;width:26%;aspect-ratio:1;overflow:hidden;border-radius:50%;z-index:20">
  <video id="pip-segment-1" class="clip" src="assets/pip-square.mp4"
    data-start="10" data-duration="4" data-media-start="2"
    muted playsinline style="width:100%;height:100%;object-fit:cover"></video>
</div>
```

时间只放在 video，祖先不重复 data-start；不加第二条人声。字幕避开圆框：缩窄到旁侧或改变垂直位置，仍按语义断行，检查全部受影响字幕。入退场可短淡化；相邻同类窗口合并，避免每句话头像闪入闪出。大画面出镜时圆框退场，避免重复两个人头。

画中画遮住主角、物件或关键文字就移动框位/调整版式，不削减内容。人物长期处于角落是否合适由目标决定；它是用户选择的出镜方式，不是掩盖不合格脸部生成的方法。

## 验收

全覆盖检查无缺口/重叠误播；源窗口开头中间末尾口型对应；切换前后一帧无错误源画面；裁切不砍额头/下巴；字幕与圆框不重叠。零音轨偏移、帧序正常、像素匹配只证明映射与编码，不证明眨眼/表情自然；这些仍须已认可基线及实际连续检查。
