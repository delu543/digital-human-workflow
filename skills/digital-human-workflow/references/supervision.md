# 以人物为核心的制作监制

用于客户交付、用户强调真人感或曾否定设计的成片。它补充 production.md 的实际验收，不替代已有声像基线，也不新增调用、上传、收费或发布权限。

## 验收优先级

1. **人物和声音**：身份、眼镜/服装等已确认特征、眼神、口型、表情、动作、呼吸和停顿。先查看干净的生成素材，再看包装后的同一段。包装不能掩盖或弥补此项不合格；不要为画面节奏机械加速声音、抹掉气口、重塑表情或把人物长期缩成角落装饰。
2. **内容完整**：把用户脚本的每段口播及明确效果分别编号，记录实际声学时间和对应图层。可选项与必选项分开。不得为了版式悄悄删句、改变观点，或把文中的假设做成事实证明。
3. **可读和一致**：用一套实际嵌入的字体、色彩和网格统一整片。仅声明字体真实存在的字重。字幕按语义断行，检查孤字、半个词、过长单行和平台边栏。先查看源视频不同姿态下的脸部范围，字幕和标题避开其运动范围；长结论使用独立画面，或安排在足够的真实空白区。
4. **运动和声音设计**：每次运动说明“什么先出现，观众读多久，关系何时揭示”。图解的答案不抢在提问前；不要全片逐字弹跳或每句换卡。音效按语义放置，独立轨道，实测混音峰值与响度，不能遮盖讲话。
5. **交付可修改**：人物、旁白、字幕、插片、音效、图解尽量分层；保持一个剪辑时间真源。剪映原生、Hyperframes 源码和已渲染片段的可编辑边界分别说明，不能拿平面视频冒充完全可编辑工程。

## 先把昂贵返工变成本地检查

- 先冻结原稿、声像基线、生成参数、费用路径和预算，再制作包装。针对包装的纠正不重新调用 HeyGen 或 TTS。
- 在整片之前，选一小段有代表性的真实素材，验证人物出镜、长字幕、图解、画幅转换和客户指定的复杂效果。复用该素材做本地设计；不要为每个设计方向重做付费人物。
- 先设计一套统一规则，再铺开全部场景。多人协作时同一负责人收拢字体、尺寸、图层顺序和安全区；“各段独立完成”不等于整片一致。
- 通常用一轮整体设计加一轮集中修正。先汇总同类缺陷并定位共同原因，再一起修正；不要逐张图无目标地改。用户新的明确反馈纳入下一轮范围，原版保留。达到已约定时间/次数/费用边界时，说明具体缺口和可选下一步，不自动重复付费。
- 正式导出前冻结工程哈希。之后若改动排版或剪辑，重新跑受影响的检查；未变的云端生成、声像基线和素材授权直接复用。

## 监制必须亲自看什么

- 初次短校准由用户认可；长片额外检查开头、中段、结尾及情绪/姿态变化。短校准不能证明长片每一秒自然。按 production.md 记录实际播放或用户确认，不编造“已听已看”。
- 截帧既看完整 9:16 原图，也看手机显示尺寸。联系表适合查一致性，不能替代关键画面单独检查。
- 检查所有画幅变化。横转竖不能只用默认居中裁切；确认手、笔、脸等语义主体保留。处理后的视频着色/特效管线可能忽略 CSS 的取景参数，必须看最终渲染。
- 检查动画开始前、开始时、关键状态和退出后。定时容器与祖先要有实际尺寸；绝对定位的子元素不能证明容器有宽高。黑底结论必须真正遮住底层人物；隐藏图层不应短暂闪现。
- 检查所有要求的倒计时、女声、老电视等特殊段落，不能只抽均匀中点。字幕和大字重复时有明确去重策略，原文仍由图解或 SRT 完整保留。
- 素材来源、生成方式和许可保存在交付清单。不要默认往画面里加“AI 情境示意”等制作说明；是否显示依用户要求和实际平台/授权要求决定，平台自带标记不得擅自去除。
- 最终检查文件解码、音画时长、口型映射、混音峰值与响度、最后一句是否完整。技术检查、静态美观、人物动态和主观听感分别记录，不能互相冒充。

## 可复用的证据

私人任务保存：需求覆盖表、声像和时间轴哈希、素材清单、场景/图层计划、关键帧与动态检查片段、验收缺陷及修正证据、实际用量与不确定项。

公共工作流只保存通用规则、匿名示例、可执行校验与格式说明。不得复制客户脚本、人物/音色 ID、录音、训练素材、私人成片、账号配置、签名 URL 或云端回执。只有本次真正验证有效的做法才能升级为默认流程；未验证的工具兼容性继续标注实验性。
