## 真实发现与处理

- 预算不足时最初会先上传音频，已改为上传前检查预算，并有测试验证上传次数为零。
- 渲染默认尝试下载专用浏览器；已让启动器优先复用本机可用 Chrome。没有浏览器时仍需要首次下载，网络与磁盘需求不能省略。
- 新编译的 base 转写曾把短样片中的4个中文字识别错，原稿一致性检查正确阻止出片。经已认可源音频与原始声学转写核对词语后，保留新转写的实际时间戳，修正并生成11条字幕成功。**不能声称 base 模型对任意中文稿零人工校对。** Codex 能确认的内容自行核对，不能确认时请用户处理该歧义。
- whisper.cpp 的 token JSON 可能包含截断的 UTF-8 标点字节。解析允许替换无效字节；替换字符不算台词，丢失真实文字仍触发原稿不一致。测试覆盖两种情况，不自动猜字。
- 检查、工程与渲染通过哈希绑定，修改配图/CSS等次级文件也会使旧检查失效；不能把旧验收沿用到新工程。

```sh
.venv/bin/python -m unittest discover -s tests -v
```
