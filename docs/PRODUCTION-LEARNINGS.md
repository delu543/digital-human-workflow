# 从实际成片沉淀的通用改进

本页归纳一条已被用户接受的长片制作中的方法，不公开其人物、稿件、参数、身份 ID、原素材或私有日志。不是每位用户都要相同装束、场景、时长或出镜方式；将偏好记录为可变契约。

| 用户反馈/尝试 | 一度不足的做法 | 固化后的规则 |
|---|---|---|
| 外观前后不一致 | 只认平台 avatar 名称或某张预览 | 分别核对目标引擎的基础 look、动作参考、当前外观约束；认可绑定实际文件 |
| 不眨眼、动作像抽帧 | 正常帧率就宣布自然；反复加“自然眨眼”提示 | 分开查技术帧序和连续表演；提示单变量试验无效就回到动作参考，不无限抽样 |
| 新高清图片仍不自然 | 把静态分辨率当作动作质量 | 使用同外观连续动作参考，核实同意、训练状态、模型支持和预览；再以实际配音校准 |
| 需要最高可用模型 | 旧配置或省预算导致实际提交较低引擎 | 用户指定要求绑定实际付费参数；账户不支持时说明选择，不静默降级 |
| 主讲停顿机械 | 碎句、统一长停顿、夸张情绪 | 按意义连贯朗读，角色音色与人物相符；少量候选试听后冻结完整声音 |
| 次要角色过分戏剧化 | 以“女性”等粗标签选音色 | 根据年龄感、角色关系、语气强度选具体角色，不固定为某个性别或年龄 |
| 人物必须全片可见 | 先只生成全屏露脸段，之后发现插片缺口型 | 先选覆盖策略，精确扣除已生成范围；缺口只用原音频/基线补，不循环无关台词 |
| 静态大照片不符合风格 | 好看照片+推近代替真实动作 | 区分图解小素材与生活场景插片；实拍先按关系/动作检索，再检查连续段和竖裁 |
| 字挡脸、孤字、字体杂乱 | 每段各自设计、只看缩略截图 | 全片统一字体/层级/安全区；字幕适配圆框，按语义断行，最终动态片检查 |
| 需要高级感而非花哨 | 用滤镜、复杂转场、人物变形做“风格” | 自然声像优先，语义镜头与克制动态图解；效果不得扭曲人物或抢先揭示答案 |
| 导出中断、反复返工 | 重启整条管线/付费任务或反复后台 Popen | 本地故障止于本地；状态持久化、一次性系统任务、独占标记与有界重试 |
| 缓存和工程过多 | 默认重复原生编辑工程/ZIP/逐帧缓存 | 一套必要素材、直接 MP4、编辑器按需；清理先核对引用与授权 |

## 有效改善与不能泛化的结论

真实动作参考相较提示词堆叠更有助于该次人物校准，最终由用户认可；这不是保证任何 16 秒输入都足够。应遵循当前供应商采集要求，并根据连续表现选择适合时长。静态 look、motion reference 和声音分别冻结后，后期只改包装，有效控制了返工和重复成本。

采用原生竖屏、具体动作匹配的实拍插片，保留已认可人物/音轨/动态图解，比随意挑选大照片更贴合此次需求。泛化的是检索和评审方法，不是默认所有人必须用国外素材、相同演员或电影镜头。

长片实际跑通了独立渲染、样本时间映射、全解码、边界与关键画面审查，并获用户接受。公共版本的代码迁移仍需匿名合成测试；私人实测不等于所有操作系统、账号和订阅的端到端保证。当前验证分层见 [VALIDATION.md](VALIDATION.md)。

## 新旧能力边界

保留会员 MCP、API、导入、声音克隆、字幕、图解和独立剪辑。不要求用户用真人出镜替代数字人，直接本地导出不依赖桌面编辑器。高级分段生成由 Codex 调用已有工具与覆盖规划器编排；完整无人值守能力仍受当前工具规则、登录、预算和主观验收条件约束。

每次经验升级必须回答：何种输入/版本上验证有效？是否能回归检查？哪些用户偏好已抽象成参数？是否增加隐私或费用边界？不把所有历史尝试都升级成默认步骤，已否定的方法只保留简短原因以避免重走弯路。
