# 数字人工作流

**把文案变成本人的全数字人视频，独立完成字幕、视频插片、镜头和混音，并交付成片与可编辑素材。**

Codex 负责理解文案、分镜与执行，MiniMax 负责用户自己的声音，HeyGen 负责干净数字人口播。字幕从实际声音对齐，默认由 Hyperframes 独立后期并直接导出成片。默认中文、9:16、1080×1920，目标约五分钟；实际时长由配音决定。

这是可安装的通用工作流与 Codex Skill，不包含作者账号、录音、私人文案、形象、密钥或个人配置。每位用户在自己的电脑保存自己的素材与账户设置。

代码与工作流版本 **v0.6.0**：将广告片的双语字幕、人物头部取景、源音频同步、摄影与材料设计、GPT生图/图生图、真实插片、音乐和限时短版整理为可选流程，并新增本地字幕生成器、时间映射审计和取景规划器。保留独立自动剪辑，不恢复已经移除的桌面编辑器专用集成。人物外观、语言、画幅、音色、风格和套餐取决于每位用户，公共仓库不包含作者的任何私人媒体。详见 [更新记录](CHANGELOG.md) 与 [广告片升级说明](docs/ADVERTISING-UPGRADE.md)。

## v0.6比原流程改进在哪里

| 原有基础 | 新增的执行与验收 |
|---|---|
| 已有声学字幕、简单标题与关键词 | 同一cue生成双语SRT和可编辑HTML；逐句查最终画面，不能为动效隐藏口播字幕 |
| 画中画和真圆蒙版 | 根据实际头部活动范围规划方形代理，核对帧数/帧率与最终位置 |
| 分段人物覆盖规划 | 进一步检查所有可见说话数字人，包括小预览，发现错台词、固定偏移与速度漂移 |
| 基础图解和关键帧 | 可选摄影/产品/品牌/信息图方向；实拍、材料、字体、语义揭示与柔和转场统一设计 |
| 素材登记与混音 | GPT生成/编辑、实拍与视频生成分工；角色声音、可听见的BGM、ducking、音效及片头尾独立规划 |
| 完整视频导出 | 可从认可成片混剪严格限时短版，保持完整句与声画映射，核验实际文件时长 |

新能力既有可执行脚本，也有需要Codex审美判断和实际工具的步骤；不是升级版本号就能保证任意素材都达到广告片质量。详见 [执行方法](skills/digital-human-workflow/references/advertising.md) 和 [验证边界](docs/VALIDATION.md)。

## 给第一次使用的人

把下面这段话发给你自己的 Codex：

> 请阅读 https://github.com/delu543/digital-human-workflow 的 INSTALL_FOR_CODEX.md，在独立目录安装“数字人工作流”和 Skill。我会提供用于创建本人数字人的照片、视频和文案。请你负责其余分镜、素材检索、字幕、动画、混音、导出和验收；只把必须由我完成的账号、平台同意、首次声像确认和费用选择合并告诉我，不使用作者的账号或素材。

首次准备后，在 Codex 输入：

> 用“数字人工作流”制作这段文案，竖屏，沿用已认可的声音、形象和预算。按语义选真实视频插片与简洁图解，保证人物自然、字幕清楚。直接给我成片。文案：……

后期也可以直接说：

> 继续剪辑上一条数字人视频，把结论移到开头；讲到孩子学习时插入对应视频，人声连续，字幕简洁，镜头轻微推近。直接出片。

广告片可以说：

> 用已认可形象做原生16:9宣传片，声音自然。英文旁白、中文在上英文在下；穿插许可实拍，必要的美术底图用GPT生成或参考图编辑。BGM要有存在感，转场柔和，人物圆框居中。按我的现有预算执行，先验证代表段。

这些是可替换的偏好，不是强制英文、横屏、持续圆框或生图。也可以要求“从已有成片混剪30秒以内，保留完整短句和字幕，不重生成”。

Codex 编写计划并执行本地剪辑，用户无需填写 JSON。只修改后期时复用已经生成的声像，不自动重新调用付费模型。训练视频用于创建本人数字人，不以真人拍摄出镜替代用户要求的数字人。

你需要亲自完成的通常只有：平台注册/订阅选择、密钥在本地隐藏输入、本人数字人创建与平台同意、第一次声音/形象试听确认、费用上限授权。其他安装、分镜、字幕、渲染、检查和打包由 Codex 执行。详见 [安装入口](INSTALL_FOR_CODEX.md)。

## 可以选择自己的计费方式

| HeyGen 路径 | 账户需求 | 自动化边界 |
|---|---|---|
| 会员 + 官方 MCP/OAuth | 当前账户支持相应功能与额度 | 受工具权限和状态查询规则约束，可能需说“继续” |
| API | 用户自己的 API key 与可用额度 | 支持提交、保存远端 ID、查询、恢复与下载 |
| 导入已有数字人视频 | 已有授权数字人声像素材 | 本地完成字幕、插片、动画和交付 |

程序不会因会员额度不足自动切到 API，不把 Pro 当成 API 余额。价格和单条预算由用户根据当前账户填写；不预设任何套餐为必选。MiniMax 国内/国际站按密钥来源配置，中文本身不决定站点。

成片长度、人物原生分辨率、水印、可用模型、动作参考及单次任务长度取决于实际套餐和账户权限；1080p 画布不能把低分辨率人物变成原生高清。高级模型名称不是自然度保证，先在该用户素材上验证。Codex 会核对当天能力和预算，列出可执行方案；不会因低额度静默降级指定模型，也不会把本地包装能力等同于已购买云端权限。详见 [费用与恢复](skills/digital-human-workflow/references/billing-and-recovery.md)。

## Codex 怎样完成制作

1. **保真与排期**：把原稿、参考片和细节拆成可追踪的要求，确定人物出镜区间与插片意图。用户不用写分镜表。
2. **人物优先**：检查训练素材、静态形象与动作参考，锁定用户认可的身份特征；先配音，再驱动干净人物。眼神、眨眼、重复动作、脸型和口型不通过时，不用包装掩盖。
3. **按动作找真实视频**：优先用 Pexels 的站内/API 搜索，按人物关系、可见动作、场景和构图检索，逐段看片并确认许可。电影台词索引只用于定位，公开可看不等于可商用。具体查询、筛选和来源记录见 [真实素材搜索](skills/digital-human-workflow/references/stock-search.md)。
4. **独立后期**：保留原声连续性，字幕从实际音频对齐；图解、动态强调、转场与音效各有目的。可以选择全屏人物或插片期间同步圆形头像，见 [人物覆盖与圆框](skills/digital-human-workflow/references/presenter-coverage.md)。
5. **实际成片验收**：代表性短片通过后导出长片；核验完整解码、时间轴、边缘、字幕、切口和真实视听。故障只修对应层，已付费的合格声像继续复用。

总入口是 [监制执行规范](skills/digital-human-workflow/references/director-runbook.md)。基础 CLI 管理任务、预算和媒体；语义选材、多角色、多段人物覆盖及定制动画由 Codex 根据 Skill 编排，**不是一个 `run` 命令自动完成所有审美判断**。素材站点的可用性、登录和下载限制也仍是实际依赖。

## 交付内容

- MP4 成片与 SRT 字幕。
- 配音、原始数字人视频、使用到的配图、分镜和真实时间轴。
- 可编辑的 Hyperframes 工程、来源/权利记录、验收结果与 SHA-256 清单。
- 默认保留一份必要素材目录；需要跨机器交接时按需生成 ZIP，不同时堆叠重复大包。密钥、账号配置和云端签名回执不进入素材包。

内置标题、关键词字幕、步骤图、带来源的柱图和插图场景；更复杂的动画由 Codex 编辑本地 Hyperframes 工程。它不会仅凭一句话自动判断所有美术要求，也不会用均分时长假装精准字幕。

独立剪辑支持本地视频/图片插片、句段顺序与速度、画中画、位置/缩放/旋转/透明度线性关键帧、音乐/音效音量和淡入淡出。字幕由本地对齐与剪辑完成，不依赖 HeyGen 烧录。可选生成工具提供插片文件后再登记来源；本版未内置通用视频生成 API。

可编辑交付是 Hyperframes 源码、独立声像、字幕与时间轴；不承诺这些文件能无损转换为任意桌面剪辑软件工程。已有旧版本工程和素材留在用户原目录，本版不会修改；新素材包仅包含当前独立工作流产物。

## 技术安装

需要 Python 3.11+、Node.js 22.15+、Git；本地中文对齐还需 C++ 编译器。首次联网下载依赖和约148MB base 模型，不会调用付费生成接口。

```sh
git clone https://github.com/delu543/digital-human-workflow.git
cd digital-human-workflow
python3 scripts/bootstrap.py
.venv/bin/python scripts/setup_whisper.py
.venv/bin/python scripts/install_skill.py
.venv/bin/python -m digital_human --workspace "$HOME/DigitalHumanData" init
.venv/bin/python -m digital_human --workspace "$HOME/DigitalHumanData" doctor
```

Windows 建议 WSL2；原生 Windows 的 Python 路径为 `.venv/Scripts/python.exe`。macOS 已执行本地媒体验证，其他系统的测试范围见 [验证说明](docs/VALIDATION.md)。无需自己写编排命令，Codex 会根据 [Skill](skills/digital-human-workflow/SKILL.md) 继续。

## 稳定性的实际边界

收费调用先保存状态，不确定结果不自动重试；本地字幕/合成失败不会重新收费生成；已完成素材按哈希恢复。用户修改文案、声像或计费路径时创建新任务，修改包装可复用既有声像。

本地导出可以使用 [一次性后台导出](skills/digital-human-workflow/references/render-recovery.md)，有次数、超时、进程树停止及同名输出保护；检查通过和文件存在仍不等于人物/画面主观验收。只保留下一次继续制作所需的素材、状态和证据，垃圾整理遵守用户当前授权和项目规则。

它仍依赖供应商权限、余额、网络和素材质量。首次样片验收不能代替每条视频的口型、字幕和视觉检查；本地五分钟压力测试也不能证明所有账户都能生成五分钟云端视频。现有验证和未验证部分明确列在 [验证说明](docs/VALIDATION.md)，不作“永不失败”的承诺。
